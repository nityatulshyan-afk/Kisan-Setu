Kisan Setu - A smart agricultural procurement system 

This is the solution proposed by me and my team for the Smart India Hackathon 2026.

KisanSetu is a smart, multi-channel agricultural procurement platform designed to reduce waiting time, unnecessary travel, and uncertainty for farmers visiting procurement centres.

Farmers often face long queues, overcrowded centres, and limited visibility into procurement status. KisanSetu addresses these challenges by helping farmers identify suitable procurement centres, book digital tokens, track their produce, and receive timely updates throughout the procurement process.

The platform aims to make agricultural procurement more efficient, accessible, and transparent through AI-assisted decision-making and digital coordination.


Key Features --

1. AI-Assisted Smart Centre Allocation

Recommends suitable procurement centres based on estimated waiting time, distance, and available procurement information.
Aims to distribute farmer visits more efficiently across centres.
Can evolve from rule-based allocation to predictive AI as historical data becomes available.

2. Digital Token Booking

Enables farmers to book tokens before visiting a procurement centre.
Helps organize queues and reduce uncertainty around arrival times.

3. End-to-End Procurement Tracking

Farmers can track the progress of their produce through the following stages:
Booked → Arrived → Weighed → Graded → Paid
This provides better visibility into the procurement process.

4. Multi-Channel Notifications

App notifications for digitally connected farmers.
SMS updates for farmers with basic mobile phones.
IVR (Interactive Voice Response) support for voice-based updates.
Sahayak-assisted access for farmers who need help using digital services.

5. Procurement Officer Dashboard

Provides visibility into centre activity and queue congestion.
Supports monitoring of procurement progress.
Can help officials make more informed decisions about centre-level operations.


Tech Stack --

Frontend: Web application
Backend and Database: Supabase, PostgreSQL
AI/ML: Smart allocation and potential waiting-time prediction
